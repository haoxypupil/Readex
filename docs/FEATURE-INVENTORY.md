# Readex 功能清单与使用指南

> - 项目：Readex
> - 版本：0.2.2
> - 文档更新：2026-11-17
> - 适用平台：Windows 10/11 x64
> - 文档定位：面向使用、验收、发布和维护的完整功能索引

Readex 是一个本地优先的 Windows 桌面电子书阅读器。它不要求登录，不接入账号或云同步，图书、阅读进度、高亮、批注、书签和设置都保存在应用旁的 `data/personal` 目录。除在线听书合成外，核心阅读流程可以离线使用。

本文档汇总当前代码已经实现的功能、操作入口、快捷键、数据边界和已知限制。架构和实现细节见 [DESIGN.md](../DESIGN.md)，听书实现见 [TTS-INTEGRATION.md](./TTS-INTEGRATION.md)。

## 2. 图书库与导入

### 2.1 导入入口

- 文件菜单中的“导入图书”
- 快捷键 `Ctrl+O`
- 书库页面的“导入图书”按钮
- 左侧栏导入按钮
- 将 `.epub`、`.mobi`、`.pdf`、`.txt` 或 `.cbz` 文件拖入应用窗口

支持一次选择或拖入多个文件。批量导入时，单个文件失败不会阻断后续文件。

### 2.2 导入处理

- 校验文件头和格式，拒绝损坏或不支持的文件。
- 检测常见 DRM 或加密标记，不尝试解密。
- 使用完整文件 SHA-256 去重，重复导入不会覆盖已有进度和笔记。
- 提取书名、作者、语言、出版社、描述、封面和章节或页数。
- 对异常的文件名和 PDF 元数据标题进行清洗与回退。
- 显示排队、检查、导入、成功、跳过、失败和取消状态。
- 批量导入时可在浮层中取消剩余任务，正在处理的单本会先完成。
- 导入时先写入临时区，成功后原子移动到个人资料目录。

### 2.3 书库管理

- 搜索书名、作者、格式、简介、文件名和标签。
- 按最近活动、导入时间、书名或阅读进度排序。
- 按未读、在读、已读完筛选，并按标签筛选。
- 查看书名、作者、格式、封面和阅读进度。
- 编辑书名、作者、出版社、简介和标签；修改后立即同步到书库和阅读页。语言和漫画阅读方向不在表单中编辑，保存时会原样保留。
- 通过书籍信息弹窗更换封面，支持 PNG、JPEG、WebP、GIF 和 BMP，最大 8 MB；封面保存为书籍目录中的文件。
- 首次打开无封面的 PDF 时，自动渲染首屏并保存为封面。
- 在资源管理器中定位导入时使用的原始文件。
- 从 Readex 书库移除图书。
- 点击封面或卡片打开独立阅读工作区。

## 3. 工作区与阅读

### 3.1 工作区

- 每本已打开的书作为一个独立工作区。
- 左侧栏展示当前打开的工作区。
- 支持关闭单个工作区，快捷键为 `Ctrl+W`。
- 重启应用后恢复打开顺序、当前书籍和最近阅读位置。
- 返回书库不会自动关闭已经打开的工作区。

### 3.2 格式支持

| 格式 | 阅读方式 | 位置定位 | 标注与搜索 | 听书 |
| --- | --- | --- | --- | --- |
| EPUB | epub.js 连续滚动 | CFI | 支持 | 支持 |
| MOBI/KF8 | 统一章节流 | 文本偏移 | 支持 | 支持 |
| PDF | pdf.js Canvas 与文本层 | 页码和归一化矩形 | 文本型 PDF 支持 | 文本型 PDF 支持 |
| CBZ | 图片页翻页（单页或宽窗口双页、从左到右或从右到左） | 页码 | 不支持 | 不支持 |
| TXT | 自动识别编码后分章 | 文本偏移 | 支持 | 支持 |

TXT 支持 UTF-8、UTF-16、GB18030、Big5 等常见编码。TXT 仍按固定字符块渲染以保证长文本性能，但目录会优先识别“第 X 章”“序章”“番外”等标题，并记录章内偏移用于跳转。PDF 按阅读区宽度自适应，页面缩放作为相对于适应宽度的倍率保存；显示设置中可开启 PDF 夜间模式，把画布反色以适配暗色主题。

### 3.3 导航与进度

- 目录面板支持 EPUB、MOBI/KF8、AZW3、TXT 和 PDF；PDF 会解析内嵌大纲，存在时显示真实章节，否则按页显示。
- PDF 和 CBZ 的阅读工具栏提供“页面”按钮，打开按需加载的缩略图网格，点击跳页，当前页高亮并自动滚动到可视区。
- 阅读菜单提供上一章、下一章和目录跳转。
- 标题栏显示当前章节和整体阅读进度。
- EPUB 使用 CFI，PDF 使用页和矩形，MOBI/TXT 使用文本偏移保存位置。
- 定位失效时使用章节、摘录和前后文回退。

### 3.4 书内搜索

- 从阅读工具栏或 `Ctrl+F` 打开书内搜索。
- EPUB、MOBI/AZW3/TXT 在可用的正文内容中搜索。
- EPUB 和 MOBI/AZW3/TXT 会标出当前匹配的文本，可用面板按钮或 `Enter`/`Shift+Enter` 在结果间循环跳转。
- PDF 在文本层中按页读取并搜索，结果定位到对应页面并高亮匹配文字。
- 扫描版 PDF 没有文本层，因此不能搜索、选择或标注。
- CBZ 漫画按图片页显示，没有文本层，不参与高亮、笔记、搜索和听书；支持左右按钮、滚轮、`Space`/`PageDown` 和方向键翻页，并记录页码进度。
- 阅读方向按书保存在书籍信息中（从左到右 / 从右到左），阅读器右上角可切换；从右到左时左侧按钮和左方向键表示下一页。
- 宽窗口（阅读区至少 760 px）可开启漫画双页，固定 (1,2)、(3,4) 组合并预加载下一组；双页为全局设置。
- CBZ 首次打开时会把图片解压到 `cache/parsed/<bookId>/pages`，并提取首张图片作为封面；缓存可以安全删除并重建。

### 3.5 沉浸阅读与翻页

- 阅读时按 `Ctrl+Shift+F` 或从视图菜单进入沉浸模式，隐藏阅读工具栏和状态栏。
- 沉浸模式下右上角保留低透明度退出按钮，按 `Escape` 也可退出。
- `Space` 或 `PageDown` 向下翻一屏，`Shift+Space` 或 `PageUp` 向上翻一屏；EPUB 内嵌页面同样生效。
- 翻页会暂停自动滚动，输入框、按钮和弹窗获得焦点时不会触发。

### 3.6 跨书全文搜索

- 侧栏“全文搜索”或视图菜单进入，输入关键词后按 `Enter` 搜索。
- 覆盖 EPUB、TXT、MOBI 和 AZW3；PDF 暂不进入全局索引，请打开书籍后使用书内搜索。
- 每本书最多返回 30 条，单次搜索最多返回 200 条。
- 首次搜索某本 EPUB 时会提取正文并缓存到 `cache/parsed`，之后搜索直接复用。
- 点击结果会打开对应书籍：TXT/MOBI 定位到精确文本偏移，EPUB 定位到对应章节。
- 页面会显示书名、格式、章节名和命中上下文。

## 4. 高亮、笔记与书签

### 4.1 选中文字

选中正文后可以：

- 添加黄色、绿色、蓝色或粉色高亮。
- 在笔记编辑器中填写标签，用逗号分隔，最多 8 个。
- 复制当前选区。
- 添加评论笔记。
- 删除已有标注；在选区正确匹配时可删除对应高亮。

### 4.2 文本右键菜单

- 在选中文字上右键打开文本操作菜单。
- 菜单提供高亮、添加笔记、复制和添加书签。
- 点击其他位置、切换窗口或按 `Escape` 关闭菜单。
- 菜单会根据真实尺寸在窗口边缘自动翻转到上方或左侧。

### 4.3 笔记编辑器

- `Enter` 保存笔记。
- `Ctrl+Enter` 或 `Shift+Enter` 插入换行。
- 编辑已有笔记时可展开“历史版本”，查看最近 10 次编辑前的笔记和颜色；点击历史项可把旧笔记载回编辑器。
- 笔记编辑器提供标签输入，编辑时回显已有标签；标签不参与历史版本。
- 笔记与原文定位绑定，可从笔记列表跳回书的对应位置。

### 4.4 书签

- 使用阅读菜单或 `Ctrl+D` 在当前阅读位置添加或移除书签。
- 选中文字后也可以通过右键菜单添加选区书签。
- 书签和笔记共用本地注解存储。

### 4.5 笔记面板

- 阅读侧栏展示当前书的高亮、评论和书签，书签单独分组显示。
- 支持点击定位、删除和导出当前书 Markdown。
- “所有笔记”页面支持跨书搜索笔记内容（含标签），并可按书籍、类型、标签和时间筛选。
- 支持把全库笔记导出为单个 Markdown 文件，按书分组。
- 全局搜索当前只覆盖笔记，不建立全库正文全文索引。

## 5. 外观与阅读设置

### 5.1 主题

- 深色
- 明亮
- 护眼
- 自定义背景色、文字色和强调色

主题同步应用于标题栏、侧栏、弹窗、阅读区和窗口原生按钮区。

### 5.2 字体

内置字体无需用户安装：

- 思源宋体
- 霞鹜文楷
- 站酷小薇

也可以选择系统宋体、黑体、楷体或默认字体。内置字体使用 SIL OFL 1.1 许可，许可证随安装包提供。

### 5.3 排版参数

| 设置 | 范围 |
| --- | --- |
| 字号 | 13 至 34 px |
| 行距 | 1.2 至 2.6 |
| 段距 | 0 至 2 em |
| 字距 | 0 至 0.12 em |
| 内容宽度 | 520 至 1100 px |
| PDF 自适应倍率 | 0.6 至 2.2 倍 |
| 滚轮步长 | 24 至 120 px |
| 浮框宽度 | 360 至 1200 px |
| 浮框高度 | 120 至 600 px |

设置可以单独恢复排版默认值，主题颜色不会被重置。

### 5.4 阅读布局与阅读目标

- EPUB 支持三种布局：连续滚动、分页单栏、分页双栏（宽窗口自动双栏，窄窗口退回单栏）。
- 切换布局会重建 EPUB 渲染，并通过最近一次 CFI 恢复当前页。
- 分页模式不支持自动滚动，切换布局会停止听书和自动滚动。
- TXT、MOBI/AZW3 和 PDF 始终使用连续滚动。
- PDF 支持双页模式，按行并排显示两页，适合宽屏；可在显示设置中开启。
- 每日阅读目标范围为 0 至 180 分钟，0 表示不设目标；统计页显示今日进度和剩余时间。
- 统计页提供年度月度柱状图、今年阅读天数、历史最长连续和已读完数量。

## 6. 精细滚动与自动滚动

### 6.1 精细滚动

- 默认滚轮步长为 48 px，可在 24 至 120 px 之间调整。
- 默认开启 150 ms 平滑滚动。
- 阅读区右侧提供向上和向下按钮，每次按设置的步长移动。
- 同时处理标准鼠标滚轮、高分辨率触控板和按行滚动事件。

### 6.2 自动滚动

- 右侧播放按钮或 `Ctrl+Shift+A` 开始或暂停。
- 支持 1 至 100 级速度，约对应 4 至 120 px/s（低速段每级差异更明显）。
- 使用真实时间差保持匀速，低速时累计小数位移。
- 可关闭颜色提示，或选择“视线色带”和“逐句渐变”。
- 标注颜色可自定义，临时标注不会写入用户笔记。
- 手动滚动、拖动滚动条或点击正文后自动暂停。
- 到达文档末尾后停止并清除临时标注。
- 自动滚动与听书互斥，开始其中一项会停止另一项。

## 7. 听书

### 7.1 能力

- 支持 TXT、MOBI/KF8、EPUB 和文本型 PDF。
- 支持在线神经语音和 Windows 系统离线语音两种引擎，可在听书设置中切换。
- 从当前视口内第一句完整文字开始朗读；如果先选中文字，则从选中位置开始。
- 支持播放、暂停、继续和停止。
- 提供四种中文神经音色：晓晓、晓伊、云希、云健。
- 支持 0.6 至 2.0 倍语速和 0 至 100% 音量。
- 支持 15、30、60 分钟定时停止，手动停止听书时定时器自动取消。
- 当前句高亮，播放时自动推进并滚动到下一句。
- 当前句开始后预取下一句，减少句间等待。
- 支持跨章节和跨 PDF 页面连续推进。
- 浮框内提供紧凑听书控件，可独立播放。

### 7.2 缓存

听书缓存位于 `data/cache/tts`，仅用于在线语音；系统离线语音不生成缓存。缓存使用音色、语速、音量和文本计算缓存键。相同内容再次朗读会命中缓存。缓存约达到 300 MB 后按最近访问时间清理，不占用个人资料目录；个人资料管理页面显示缓存占用并支持一键清空听书缓存。

### 7.3 联网与隐私

在线听书使用 Microsoft Edge 在线语音服务。当前正在合成的句子会发送给该服务，因此在线听书不是纯离线功能。应用不会上传图书文件、笔记或完整书库。系统离线语音由 Windows 本机合成，不发送朗读文本，但需要系统已安装对应语音包。

扫描版 PDF 没有文本层，仍不支持听书。

## 8. 浮框阅读

阅读工具栏中的“浮框阅读”会隐藏主窗口并打开独立无边框窗口。浮框只显示书籍内容，不显示应用工具栏、目录、搜索和笔记侧栏。

### 8.1 窗口行为

- 浮框不是系统置顶窗口，只按普通窗口层级悬浮。
- 默认宽度跟随内容宽度，默认高度为 200 px。
- 窗口尺寸受当前屏幕工作区约束，最小尺寸为 360 x 120。
- 浮框保留独立阅读实例；从主界面再次进入同一本书时直接复用。
- 隐身模式：去掉边框、圆角与窗口阴影，视觉上只保留背景色和正文；窗口拖动不受影响，右上角隐身开关低透明度常驻，其余按钮悬停后浮现，状态会记住。

### 8.2 拖动与选择

- 点击正文外空白区可以拖动窗口。
- 点击左侧、右侧或底部边框可以拖动窗口。
- 顶部内侧提供原生拖动带，避开 Windows 边缘缩放热区。
- 鼠标移动超过 4 px 后才判定是拖动窗口还是选择文字。
- 正文已经形成文字选区时优先保留选择，不移动窗口。
- 按钮、输入框、下拉框、链接和听书或滚动控件不会触发窗口拖动。

### 8.3 按钮

- 右上角最小化按钮只收起浮窗，窗口实例和阅读位置保留。
- 右上角关闭按钮退出 Readex。
- 右侧滚动控制组提供上移、下移、自动滚动、速度调节、听书和返回主界面。
- 按 `Escape` 返回主界面。

## 11. 个人资料、备份与隐私

### 11.1 目录结构

打包版首次启动后会在 `Readex.exe` 同目录创建：

```text
data/
  personal/
    settings.json
    library.json
    stats.json
    books/<bookId>/
      source.epub|mobi|pdf|txt|cbz
      cover.jpg | cover.png   # 可选，导入或手动设置的封面
      metadata.json
      annotations.json
      reading-state.json
  cache/
    import/
    parsed/<bookId>/
    tts/
```

`personal` 保存图书副本、设置、工作区、阅读进度、高亮、批注和书签，是需要迁移或备份的数据。`cache` 保存解析结果和听书音频，可以删除并重建。

### 11.2 个人资料管理

- 查看个人资料的绝对路径和缓存路径。
- 查看图书数量、笔记数量、个人数据和解析/听书缓存占用。
- 将 `personal` 备份为 ZIP。
- 从历史 ZIP 备份恢复：先解压到缓存临时目录，校验结构后再替换当前个人资料；失败时保留原目录。
- 一键清空听书缓存，并显示释放的磁盘空间。
- 在资源管理器中打开个人资料目录并复制路径。
- 清空前再次确认，只删除并重建 `personal`。
- 清空不会删除用户导入前的原始电子书，也不会删除 `cache`。

### 11.3 安全边界

- Renderer 开启 `sandbox` 和 `contextIsolation`，关闭 `nodeIntegration`。
- Renderer 只能通过 preload 白名单调用 `window.readex`。
- 图书通过支持 HTTP Range 的 `readex://` 协议按需读取，不把任意路径暴露给页面。
- CSP、导航限制和新窗口限制默认启用。
- 打包环境的渲染窗口阻止 HTTP、HTTPS、WebSocket 请求；在线听书只由主进程语音服务访问网络。
- EPUB iframe 禁止脚本内容，MOBI/TXT 生成的 HTML 经过清理。

## 12. 格式与功能边界

- 不绕过 Kindle、Adobe 或出版社 DRM。
- 扫描版 PDF 可以显示，但当前没有 OCR，因此没有文本选择、搜索、标注和听书。
- 目前没有账号、云同步、多设备同步或自动更新。
- 系统离线语音依赖 Windows 已安装的语音包，可用音色取决于本机。
- 阅读统计只累计 Readex 窗口在前台且有焦点时的时长，不包含后台阅读。
- 分页和双栏目前只支持 EPUB；PDF 双页阅读尚未实现。
- 全局正文搜索覆盖 EPUB、TXT、MOBI 和 AZW3；PDF 和 CBZ 不进入全局索引。
- 在线听书依赖 Microsoft Edge 在线语音服务，网络异常时可能失败。
- 浮框默认不是置顶窗口，可能被其他普通窗口覆盖。

### 13.3 Windows 产物

```powershell
pnpm dist:green   # 绿色目录 ZIP，启动最快，推荐日常分发
pnpm dist         # 单文件 Portable EXE，便于携带
pnpm dist:dir     # 未压缩的 win-unpacked 目录
pnpm dist:signed  # 类型检查、签名环境校验、Portable EXE 和 ZIP
```

主要输出：

```text
release/Readex-0.2.2-x64.zip
release/Readex-0.2.2-portable.exe
release/win-unpacked/Readex.exe
release/Readex-0.2.2-绿色版-轻量分享包.zip
```

`build-share-zip.bat` 会完成依赖检查、构建、语言包裁剪、排除个人数据、压缩 ZIP 和 SHA-256 计算。Portable EXE 每次启动前需要释放 Electron 运行环境，启动速度慢于绿色目录版。

代码签名发布需要设置 `CSC_LINK` 和 `CSC_KEY_PASSWORD`：

```powershell
$env:CSC_LINK = 'D:\certificates\readex.pfx'
$env:CSC_KEY_PASSWORD = '证书密码'
pnpm dist:signed
```

不要把证书或密码提交到仓库。
